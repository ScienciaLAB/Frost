Frost

A free, open-source menu bar manager for macOS. Hide, rearrange, and restyle your menu bar items — now working on macOS 26 Tahoe.

Download Frost
Requires macOS 14 or later · Release notes · Source code

Features

Hide menu bar items

  • Hidden and always-hidden sections
  • Show items on hover, click, or scroll
  • Automatically rehide items
  • Search all menu bar items

Arrange your layout

  • Drag and drop individual items
  • A separate bar for hidden items, ideal for MacBooks with a notch
  • Adjustable item spacing
  • Hide app menus when they overlap items

Style the menu bar

  • Solid and gradient tints
  • Shadows and borders
  • Rounded and split shapes

Hotkeys and more

  • Toggle sections and the search panel
  • Toggle application menus
  • Launch at login
  • Automatic updates

Install

  1. Download Frost.zip, open it, and move Frost.app to your Applications folder.
  2. Frost isn't notarized by Apple yet, so macOS blocks it the first time. Clear the download flag in Terminal: 
    xattr -dr com.apple.quarantine /Applications/Frost.app
  3. Open Frost from Applications or Finder, then grant Accessibility and Screen & System Audio Recording when asked. After granting Screen Recording, quit Frost and open it again. If you used Ice before, Frost imports your Ice settings on its first launch.

If Frost says permissions are missing even though they look enabled in System Settings, remove Frost from both permission lists (or run tccutil reset Accessibility com.sciencialab.Frost and tccutil reset ScreenCapture com.sciencialab.Frost), then open Frost and grant them again.

About

Frost continues Ice by Jordan Baird, which is no longer maintained. It builds on Ice's unreleased macOS 26 work and fixes from the Ice community, so it runs on macOS 26 Tahoe.
